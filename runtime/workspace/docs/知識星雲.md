# 知識星雲

保留 Obsidian 原筆記，從目前工作區 `brain.json` 指定的 vault 產生可重建 HTML。HTML 不是新的知識真源。

## 開啟與自動同步

完成工作區安裝後，雙擊工作區 `assets/開啟知識星雲.cmd`。它會啟動只供本機使用的連線，並在瀏覽器開啟星雲；不用先輸入命令。同一工作區重複開啟會沿用原有服務，不會另開一套資料。

已有星雲頁時，服務會立刻打開現有畫面，同時在背景重建；重建完成而內容有變，打開中的頁面會自動更新，不用等候或重開。新工作區第一次開啟，才要先等首次建立完成。

連線期間會自動察覺已登記筆記、概念、成果頁及明列預覽圖片的變動。連續兩次觀察穩定後重建，頁面每五秒檢查新版，空閒時自動載入，保留搜尋、色系、視角、選取及靜觀模式。拖動、輸入或開著圖片視窗時會稍候；也可按「同步最新成果」手動重試。正式開啟入口遇到短暫等候會讀回同一同步收據，不會重複提交；未完成會如實顯示仍在同步。錯誤資料不會取代上一版星雲，修好後會自動重試。

正常新增或修訂成果、重建成果目錄時，也會更新工作區已安裝的星雲。同步只更新閱讀畫面，不會重新分析文章或改寫原筆記。

連線只監聽 `127.0.0.1`，不會上載資料或啟用背景研究排程。關閉連線頁面後，服務閒置三分鐘便結束。直接開啟 vault 內 `outcome-pages/nebula.html` 仍可離線閱讀；離線頁面不能自行掃描硬碟，按同步會提示使用上述啟動檔。

## 探索知識

- 搜尋涵蓋全部已投影節點。星雲可選全部節點、知識成果或主題與概念；「上一區／下一區」可走遍完整資料，每區最多 96 個，並非只顯示固定前 96 個。
- 選取節點可看摘要、直接相連的線索及其筆記原句，並開啟實際成果頁。總覽節錄最多 48 條關係；指向時優先顯示本區連線，最多 96 條。內容卡的線索每頁 30 條，相鄰節點過多時也可逐區探索。
- 「星雲主題群」可定位一群並調整視角。分群根據已保存的連線計算，不新增語義或因果關係；跨群連線保留，主群不代表唯一歸屬。兩點距離不是相似度或關係強度的量尺。關係改變後，位置可重新排列。
- 清單可選成果、概念或全部節點，每頁 40 項。群篩選只作用於星雲，清單仍涵蓋全庫。搜尋會明示符合數量；「清除搜尋」可回完整清單。清單與星雲共用搜尋和選取，返回成果頁可保留同一分頁內的閱讀位置；重設視角會清除搜尋與選取。
- 圖片預覽只讀筆記明列的資訊圖或案例截圖。可切換柔和色調／原色、打開原色大圖；不改原始圖片。概念的相關成果圖片只來自明列的直接來源，沒有圖片便顯示文字提示。手機內容卡保留返回操作。

## 星之搖籃

按頂列的星之搖籃按鈕打開面板，依次走過三步：① 相遇、② 孕育、③ 誕生。把幾顆星放入搖籃，由 AI 讀這些筆記，寫成新的思考紀錄；存好後它會成為星雲中的一顆新星。

- **抽星相遇：** 搖籃是空的時，先揀範圍（跨界、拉扯、新知），再按「✦ 偶遇」。頁面會抽出三顆各有角色的星（例如拉扯者、新秀、遠客），播放約六秒的相遇儀式，然後用相遇卡交代這一組：稀有度（常見、少見、罕見、傳說）、每顆星被抽中的原因，以及可以開始問的起點問題。不想看動畫可按「略過動畫」；開了「減少動態」也不會播放。
- **鎖定與重抽：** 卡上可鎖定想留下的星，再按「重抽未鎖定的星」只換其餘位置。在概念或成果的內容卡按「以它為主角抽夥伴」，會以這顆星為主角，另抽兩位夥伴（思考紀錄形成的新星沒有這個按鈕）。庫內可抽的概念不足三顆時，會如實說明只放入幾顆。
- **卡與天空對照：** 相遇期間，卡上每一列和天空中那顆星的名牌用同一個編號（①②③）。滑鼠指着或鍵盤移到卡上某一列，天空中對應的星會亮起，方便一眼對上。
- **開始孕育：** 由本機服務打開星雲，而且已在「AI 設置」批准一個背景 AI 時，深入思考及找連結的第 ③ 步會出現「開始孕育」。背景 AI 會寫答案、核對引文，再由另一個全新的 AI 獨立覆核，通過後存成思考紀錄並成為新星。孕育在本機服務背景進行，可以按「停止孕育」，也可以離開頁面；再打開星雲會繼續顯示進度，頂列會標示「孕育中」的數目。選「✦ 先觀星」時，AI 先讀這幾顆星，擬出 5 條不同角度的問題給你揀，你揀定才開始深入思考。
- **仍可複製指令：** 沒有可用的背景 AI、直接打開離線的 `nebula.html`，或選了「創作」「向外延伸」時，第 ③ 步維持「複製指令」，可貼到 Claude Code 或 Codex 照做。

## AI 設置

首頁「進入星雲」旁的「AI 設置」，或第 ③ 步的「前往 AI 設置」，會打開同一個面板。它會偵測這部電腦的 Claude Code 及 Codex：是否已安裝、版本、是否以個人帳戶登入，以及能否在鎖緊的範圍內運行（只可讀寫自己的工作資料夾、不能連網）。由你揀一個並批准；背景孕育只用你已登入的帳戶，不用 API key，也不會自動換另一個 AI。兩個都不可用時，仍可用「複製指令」。

Codex 的鎖緊測試目前只在 Windows 核實；其他系統會如實顯示暫不可用。設定及每次孕育的紀錄存於工作區 `.reader-runtime/cradle/`，思考紀錄則與平時的深入思考一樣存入你的 vault。

## 畫面與靜觀模式

可拖動視角，並用按鈕、滾輪或雙指縮放至 1×–5×。色系提供紫藍星雲、冰青極光、玫瑰暮光及暖金星塵；只改光霧配色，不改節點分群與關係，並記住同一分頁的選擇。「減少動態」會停止自動光霧、粒子及慣性動作。

按「靜觀模式」可在網頁內觀看星雲時鐘，顯示裝置本地的 24 小時時間、日期及星期。點一下畫面或按 Esc 返回原有搜尋、選取和視角。自動接收資料更新會保留靜觀模式；手動重新載入則回探索畫面。時鐘不改系統鎖屏或休眠設定。光脈衝與流光只是視覺回應，不表示因果或資料真的正在傳送。

## 維護與邊界

以下命令供工作區助手維護，日常使用不需要手動執行：

```text
python tools/knowledge_nebula.py --root .
```

打開自己的 `vault/outcome-pages/nebula.html`。每次執行重新讀取來源 registry、canonical source note、concepts 的 `graph_node` 筆記及實際成果頁。新增、修改、刪除會在重建後反映；不回寫筆記、不自行建立語義關係。缺失成果頁保留節點、列出警告並停用閱讀連結。無效 registry／越界路徑不替換既有畫面。

已受管工作區會先核對 runtime 是否仍與安裝版本一致。核對未能完成或發現差異時，星雲會保留上一版並暫停同步；請由工作區助手按現有受管更新或修復流程處理，再重新開啟。不要手改 hash、複製其他工作區檔案或刪除自己的筆記來繞過這個保護。

持續編輯時，可在前景執行：

```text
python tools/knowledge_nebula.py --root . --watch --interval 5
```

這是維護人員的前景監看，每輪完成後等五秒再重讀，只有內容改變才換掉生成頁；按 Ctrl+C 停止。它不是上述雙擊入口的必要步驟，也不是 Obsidian 插件。
