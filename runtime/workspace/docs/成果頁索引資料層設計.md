# 成果頁索引資料層設計

本文件擁有閱讀入口、目錄、思考紀錄與可重建索引的規則。Vault 的 Markdown、registry、assets 與思考紀錄是真源；HTML、JSON、縮圖及日後的 SQLite 皆可重建，不反寫內容。

## 1. 三種閱讀層

| 入口 | 責任 |
|---|---|
| 本可攜包的 `index.html` | 日常工作首頁，連到本次 vault 的成果與命令表已啟用的操作；提供完整 brain-* 入口，複製提示交給 AI；保留使用者的工作首頁 |
| Vault/成果頁總覽.md | 輕量入口面板，連到閱讀目錄、來源使用說明和真源邊界；不複製全量來源清單 |
| Vault/outcome-pages | index.html 總覽、knowledge.html知識目錄、thinking.html思考紀錄目錄、個別成果閱讀頁 |

Obsidian Bases可按來源、KP、APP及維護狀態篩選，仍不取代筆記正文。

## 2. 來源成果頁

來源詳情頁讓讀者理解來源、讀完整正文、查看資訊圖、知識點、個人應用、複利洞見、相關扣連與可行動問題。來源標題、作者、發布資料和引用作品要分清，不能把使用者貼文的引用作者誤作貼文作者。

開首先補新手背景，交代來源核心、值得深讀位置及圖像用途；不寫內部任務、生成過程、治理或工作區訊息。個人相關度只回答對使用者工作、學習、生活、選擇、創作或採納的影響。舊應用判斷是時間點快照，新判斷要保留修訂痕跡。

目錄優先按 registry及 canonical paths 找正式 source/APP；不能因舊副本存在而使用錯資料。所有圖片要真 PNG/IHDR且引用可讀回，不以檔案副檔名判斷。重複、斷橋、空泛 AI 句子、偽完成或內部流程語會令本篇 reader quality gate停在 needs_review。

## 3. 索引資料

正式欄位來源維持 Writer規格。可重建 row 至少分開 source_id/title/summary、source_input_kind/source_identity、來源與日期、用途、採納/品味/複利/人工修正狀態、canonical source/APP/outcome/asset相對路徑、KP及扣連數量。多值用途、關係、場景與月份作 facets，不塞成混合單格。內部值與中文顯示值分開，不能重複創造狀態枚舉。

`outcome_index_builder.py --dry-run --json` 只讀資料並報 row count、缺欄位、facet分佈、大小估算及第一頁sample。它不是持久化 SQLite/FTS 或萬筆效能的證據。本版不提供 SQLite server、背景刷新或大規模效能保證。

## 4. HTML 閱讀介面

| 頁面 | 功能 |
|---|---|
| index.html | 兩類計數，各最多四項最近成果及待核對入口；不重複完整列表 |
| knowledge.html | 標題/摘要搜尋、類型與狀態篩選、排序、分頁 |
| thinking.html | 問答思考紀錄的問題／判斷搜尋、狀態篩選、排序及分頁；不計入原始來源。保存真源及完成條件見語義圖規格「思考紀錄保存」。 |

目錄內嵌最小資料，不依賴 fetch、後端或背景server。預設每頁20項，只渲染目前結果頁；搜尋、篩選、排序、頁碼寫入網址，返回時保留位置。無 JavaScript仍保留基本成品連結。舊 page-NNN.html可保留前往新目錄相應頁碼的連結，不展示過期內容。

卡片只顯示標題、摘要/定位、類型/日期、必要狀態、預覽及入口；不塞入全文KP和扣連。預覽完整按原比例顯示，不能裁圖或因卡片拉伸留下大片空白。思考紀錄不計入原始來源數。

## 5. 思考紀錄與共同閱讀介面

### 5.4 思考紀錄與更新流程

`python tools/outcome_page_generator.py --refresh-index --json` 重建三頁目錄、思考紀錄 HTML、筆記閱讀頁及 `vault/成果頁總覽.md`；不重新分析來源、不重生歷史來源正文。由閱讀服務發起時，目錄更新先完成，再只重建一次星雲；直接生成器維持原有完整更新行為。問答完成只要求自身保存與導航讀回；無關歷史警告不等於本题保存失敗，也不代表整庫健康。

2026-10-01 退役自動思考白板：不提供 brain-canvas／canvas 建立指令，不掃描、匯出或把 `.canvas` 列入成果目錄。既有人工資料保持原樣，指定刪除另依使用者授權。舊白板 HTML 只保留一次性轉向現行入口，刷新不再產生白板。知識網、原生 Obsidian 使用與來源資料不受此退役影響。

### 5.5 共用外觀、導航及驗收

現行首頁、安裝說明、成果總覽、知識成果、思考紀錄及有效閱讀內頁沿用冷灰紙底、淺白面板、深藍文字與淡光霧。`tools/reader_theme.css` 保留既有閱讀佈局；`tools/reader_visual.css` 擁有共用色彩與材質，`tools/reader_passage.js` 擁有進出星雲過場、色系承接與返回搜尋位置，均由 `tools/reader_shell.py` 嵌入離線頁，重建後仍保留。各生成器保留其結構與操作；星雲的字體、shader、動態與四款色系由原星雲模板擁有，共用閱讀樣式不覆蓋星雲。日常首頁仍由 tools/daily_home.py、assets/guide/daily-home.html 與 assets/guide/version.json 的共用來源生成。

共同導航是工作首頁、成果總覽、知識成果、思考紀錄；詳頁保留來源、原筆記及返回原搜尋位置。路徑按所在工作區產生，不連去另一個人的庫。合成示例只在套件安裝說明中收合展示；日常首頁按 brain.json 的 guide 與 vault 連到自己的成果，初次安裝從空白開始。最近內容及數量由成果目錄擁有，首頁只連結目錄。既有正式成果頁不為換首頁而重生；新生成的導航使用本工作區入口。

验收涵蓋 0／1／30／200 筆目錄、搜尋、分頁、正文保留、來源跳讀、桌面／手機共同導航與離線互動。另放一份無效 `.canvas` 作反例：保存答案及刷新仍能完成，沒有白板輸出；原檔未被觸碰。思考地圖與語義覆核沿語義索引規格驗收，不另建第二套規則。

## 6. 通用手冊維護

手冊只路由規格及工具，不能保存第二套產品規則或聲稱整個專案通過。新的工具入口、閱讀路徑或功能限制改變後，先讀對應owner再更新手冊。source fingerprint只能指出變動，不證明語義一致。

手冊驗收包括全部用途可發現、相對連結可開啟、複製/失敗fallback、搜尋無結果、展開、列印與手機/桌面閱讀。不含個人絕對路徑、私人成果、憑證、第三方追蹤或未交付的操作按鈕。列印成PDF只是保存手冊，不代表知識報告匯出功能。

本可攜包的展示名稱與日常首頁更新由 `scripts/setup_workspace.py --set-display-name` 擁有；它只更新本可攜 workspace 的 `brain.json` 展示資料及 `index.html`，不改歷史筆記、來源或作者。本版沒有既有工作區的完整升級路徑；需要變更首頁時修改產品來源後重新 build，不能直接改已生成頁或以重新初始化代替更新。
